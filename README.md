# The Kyle Chronicles · The Acorn Accord

A two chapter, single player browser game. This is a static site: there is no build step, server runtime, or package installation.

## Publish

Upload the contents of this folder to the document root of any static website host. The entry page is `index.html`. Keep the `assets/` directory and all CSS and JavaScript files in their current relative locations.

The game runs in modern desktop and mobile browsers. Google Fonts are loaded from Google Fonts; if that service is unavailable, the page uses its CSS fallback fonts. Game progress lasts only until the page is refreshed.
